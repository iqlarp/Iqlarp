1. Logging Fundamentals

Logging is the process of recording events and activities generated by operating systems, applications, servers and network devices.

Types of logging

- System logs: Operating-system events and errors.
- Network logs: Network connections and traffic metadata.
- Access logs: Requests made to websites and services.
- Authentication logs: Successful and unsuccessful login attempts.
- Security logs: Security events and alerts.
- Application logs: Application activity and errors.

2. Logging in Cybersecurity

Logs help security professionals:

- Investigate suspicious activity.
- Identify failed login attempts.
- Monitor network connections.
- Investigate security incidents.
- Establish timelines of system activity.

3. Logging and OSINT

OSINT stands for Open-Source Intelligence.

It involves collecting and analysing publicly available information.

OSINT can involve:

- Historical DNS information.
- Website archives.
- Public incident reports.
- Publicly accessible technical information.

Logging and OSINT are different disciplines, but they can complement each other.
